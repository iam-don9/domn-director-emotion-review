## 真实产出样例

下面是这个技能**实际会产出**的东西（抽自仓库内的 references/ 真实交付样例），不是抽象描述：

```text
输入：一段分手戏剧本（SCREENPLAY，高置信度——含场景标题、动作段、对白与括号提示）。
情绪戏诊断：她(挽留)的即时目标=让他留下；障碍=他已死心；转折点在他说"我累了"后她第三次伸手又收回。
真人感检查：第3句"她崩溃大哭"是标签、无可拍动作；改为"她伸手触他袖口，指尖至腕骨停住，肩线下沉半寸"。
节奏检查：对白密度过高、无反应留白；建议每句后留半拍静默。
问题清单：
  P0 「他转身」无前因，权力反转凭空发生——补一处视线回避。
  P1 「她心碎」改为可拍：下颌微颤、下唇内抿、不接话。
  P2 结尾缺余韵动作。
修订片段（仅改受影响句）：
  她（轻声）：……别走。
  她伸手，触到他袖口，指尖停在腕骨上方，没有握住。
```

## 是什么

把情绪戏当成「镜头前的真行为」来审——先辨清它是剧本还是生视频提示词，再逐拍审查微动作与对白绑定，给出可拍、可信的修订。 本仓库是一个 Agent 技能（SKILL.md 为唯一权威定义），把上面的方法论沉淀为可被对话触发的可执行流程。

## 为什么不同

核心是「先分类、后审查」——绝不把剧本偷偷改成视频提示词(或反之)，并用「身体部位+动词+方向+强度+拍点+抑制」的紧凑可拍句式替换「心碎/电影感」这类标签。

## 怎么做（工作流）

> 先分类后审查；标签换可拍句式

1. **输入分类** — 判定 SCREENPLAY / VIDEO_PROMPT / MIXED 及置信度
2. **情绪脊线** — 抽即时目标/障碍/战术/转折/权力反转
3. **微动作审计** — 眼/睑眉/口颌/呼吸声线/手姿/空间节奏六通道逐拍
4. **分支评审** — 剧本走 4A，提示词走 4B
5. **问题清单** — P0/P1/P2 标注，每条指向原文句
6. **修订交付** — 只改受影响片段，保格式与归属
